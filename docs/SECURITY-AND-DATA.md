# Data boundaries and launch gates

The local app is for one trusted operator on a loopback address. Its brand cookie selects the workspace; it is not an authorization boundary. Do not share an exposed server, provider keys or local data directory with unrelated clients.

The starter was made as a source-only export with new Git history. The old database, client folders, documentation, media, feedback, learned rules, benchmarks, environment, logs, caches and tests were not copied. Remaining generic methods are application behavior, not a library of customer examples. Keep the initial installation empty until the new client supplies resources.

Tracked-file CI rejects runtime folders, credential-shaped values, large accidental bundles and personal workstation paths. A separate private fingerprint review is performed before publication. A future commit that intentionally reintroduces a client name may pass generic checks; review every Git diff and never stage runtime directories with force.

Hosted access requires verified user sessions; organization and brand membership on every query/action/file/job; private object storage; encrypted OAuth tokens; scoped worker credentials; per-tenant retrieval; signed webhooks; cost reservations; audit logs; tested export/deletion and restore. The current platform contracts demonstrate parts of that model but are not connected to local app routes.

Region intention: India. Database and object storage must use explicit India regions, with backups/logs/worker deployment verified. Slack, external account APIs, AI providers and support tools can process data outside India. Resolve processor contracts and outbound-content policy before enabling them. Review the applicability and phased commencement of Indian privacy rules with counsel; this project does not certify legal compliance.

Before live spend, choose the provider, current model, input destinations and limits. Exclude customer/order identifiers from prompts. Before any future ad write or public publication, require a separately authorized artifact revision, account, action and amount. Read-only connector access never authorizes publication or budget changes.
