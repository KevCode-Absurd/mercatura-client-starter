# Type: straight argument

The 9 beats in their natural order, said directly to "you". The baseline type: every other type is a departure from it.

- **Opens with:** the accommodation, as an observation. Used up: "You buy a coffee on the way in. Not because you like it. Because the one at home is bad." Kept: "You check the forecast before you decide whether to walk."
- **Person and tense:** 2nd person, present.
- **Beat order:** hook, problem, promise, mechanism, objection, proof, offer, risk reversal, call to action, identity line. The problem is 1 or 2 lines: the promise arrives by the third.
- **Carried by:** whichever beat is strongest for this concept. Give that beat the most words.
- **The product arrives:** at the offer, eased in.
- **Not the same as:** `unaware-observation`, which stays in the buyer's life for a third of its length before any problem is named. This type names the problem at once and gets to the promise.
- **Watch for:** reading like a checklist. The script should escalate, and each line should hand over to the next.
