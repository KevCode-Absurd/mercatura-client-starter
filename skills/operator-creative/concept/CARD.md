# Choose an argument before an execution
Each concept serves one buyer situation, one awareness assumption and one central argument. Vary seven useful sources of ideas: problem moment, identity, supported myth correction, genuine founder origin, sourced customer story, fair comparison and visible demonstration. Use only buckets the brand's evidence can sustain. Neither a palette change nor the same hook reworded is a new concept.

Use TEEP as an internal diagnostic: Trigger is the concrete moment of need; Emotion is how it feels; Evidence is the reason to believe; Payoff is the buyer's expected change. Match the payoff to the evidence. Let a picture or existing context carry a role; do not force four blocks of copy into every ad.

For a batch track persona × awareness × theme, then vary argument and visual execution. Prefer untested relevant cells over repeating the same recent proposition. Distinguish hypotheses from measured results. Rank by buyer relevance, evidence, freshness and production feasibility, without invented ROI scores.

A usable brief identifies hook/visual pairing, promise limits, proof asset, objection, real offer, CTA/destination, selected format and aspect. Declare what stays fixed and which variable a variant tests. Return only the requested number of concepts and the caller's fields.
