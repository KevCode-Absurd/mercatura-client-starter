# Make the chosen template fit the evidence

## Plan
Test the selected layout against available SKU count, product silhouette, text room, buyer/awareness, required proof and actual offer. Adapt only an incompatible slot and explain why. Respect explicit reference fidelity, format, text-free and product-free choices. Use existing fields for a compact slot contract: actual template origin or described layout type, persuasive job, product/count and text zones, fixed constraints and necessary adaptation. A format recipe without a reference is not a viewed swipe ad. Do not flatten chosen graphic or illustrated formats into a packshot. For iterations, name the changed axis and keep other control slots fixed.

## Words
Select a supported customer tension, then write exact copy for the selected slots. Research inspires language; a paraphrase or synthetic persona is not a real first-person review. Missing proof, comparison or offer evidence stays missing. Feed copy develops the same promise without adding unsupported results or offers. A template never supplies competitor facts or final copy.

## Prompt
Render the selected product/count and copy slots with their reading order and essential qualifications. Preserve product identity, selected format and explicit fidelity. Use only actual attached references, each by its role; no borrowed branding or people. Send the selected contract and relevant correction, not alternatives, the whole swipe file or this full process.

## Review
Check exact words and product references before render; inspect the delivered image plus complete feed copy at mobile size afterward. Verify pack/count, type, required proof/offer terms and image/copy agreement. Keep candidate, inspection-only and selected states distinct. Scope feedback to this image, layout, product or brand; a one-off preference is not a universal rule. Editorial scores and library impressions do not establish conversion performance. Return only requested fields and concrete defects.
