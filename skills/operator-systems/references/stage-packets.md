# Stage packet dependencies

Use this matrix to decide what goes into a stage, rather than imposing one input size on every job. `Required` describes semantic dependencies, not fixed field spelling. Existing application schemas remain the contract.

| Stage | Required input | Optional input | Complete output |
|---|---|---|---|
| Brand extraction | Supplied original documents/assets, source labels, requested schema | Relevant site pages when authorized | Structured identity, visual/voice rules, products/offers/claims, provenance, confidence and missing fields |
| Buyer synthesis | Selected product, attributed quotes, source/sample context | Relevant performance segments and objections | Persona problem, trigger, language, doubt/proof pairs, hypotheses |
| Concept/brief | Product facts, selected buyer, awareness/job, format, available proof/offer, brief directives | Distinct relevant research patterns and prior concepts | One coherent argument, evidence, hook, scene, copy and format decisions |
| Primary text/headline | Chosen argument, product and offer facts, buyer objection/language, voice rules and representative examples, requested counts/limits | Closest verified proof and winning copy patterns | Requested primary text/headlines/CTA, traceable claim references when enabled |
| Avatar selection/reference | Intended role, approved identity description, age and appearance, chosen visual medium, reference purpose | Brand mood and setting when visible | Selected identity/reference image with persistent ID and exact asset link |
| Character sheet | Chosen reference image, fixed identity anchors, required views/poses, medium and clothing continuity | Expression range requested by the brief | Required views with consistent identity, complete asset links and labeled view map |
| Storyboard planning | Complete script, selected cast IDs/reference images, product use rules, format, scene intent, pace, requested shot coverage | Relevant directing recipe | Ordered shots/frames, dialogue or narration, visible copy, framing/action/setting, continuity and durations that cover the whole script |
| Static image prompt | Final scene/layout, exact text and placement, actual product reference, packaging/use truth, palette/type/logo anchors, ratio, prohibited patterns | One matched photographic recipe | A complete image specification retaining every locked text element and reference role |
| Image generation | The approved complete prompt and required images with explicit roles | Provider-supported controls | Actual generated pixels, provider/run IDs, generation metadata and status |
| Review/judge | Actual rendered image or complete storyboard, original brief, exact copy, product/character references, applicable rules | Reference ad when fidelity is part of the task | Evidence-linked issue list and scores with confidence; only score visible/supplied material |
| Repair | Original failed artifact/field, named defect, dependencies affected by the patch | Prior failed fix only when relevant | Minimal replacement/edited image plus a new validation result |
| Report/proposal | Computed metrics/findings, coverage, period/currency/attribution labels, requested scope | Relevant sourced comparisons | Supported observations, actions and explicit scenario assumptions; no invented dollar impact |

## Preservation rules

An approved claim such as “6g per adult serving” must not become “6g” when shortening. A guarantee limited to a first order keeps that limit. Customer language is attributed research, not a testimonial by a fabricated character. A fictional avatar does not establish a real endorsement, before/after result, or credential.

Keep visual anchors concise and concrete: color with its role, type family/hierarchy, exact logo asset, packaging orientation, the character's fixed features, and reference roles. Keep brand voice through a few high-information instructions and representative source lines, not repeated adjectives. Do not turn a reference's style into a new brand prohibition.

TEEP here means Trigger, Emotion, Evidence, Payoff in an ad's argument. The buying journey's Trigger, Exploration, Evaluation, Purchase is a separate axis. Awareness and theme matrices supply candidate choices; observed evidence, the user's directions, and brand rules can justify alternatives.

When trimming optional context, remove duplicated guidance, unrelated products/personas, unused formats, human setup instructions, and illustrative output before removing useful evidence. If a budget still fails, retain complete required records and report the shortfall. Estimate tokens for planning, then measure provider usage; character count divided by four is only an estimate.
