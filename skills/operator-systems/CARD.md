# Efficient creative stages

- Resolve the chosen brand, product, buyer, offer, format, reference, and checks before composition. Preserve user and app settings.
- Include required stage dependencies before optional examples. Keep whole claim scope, exact locked text, selected offer terms, brand anchors, reference role, and uncertainty that changes a decision. If they do not fit, enlarge or split the task.
- Reuse stable rules and facts as a cacheable prefix. Deduplicate by meaning; select optional whole records by relevance and source strength. Do not truncate required facts or raw text blindly.
- Copy receives voice and buyer language; design receives visual DNA. Both receive facts they will state. Judges receive the actual artifact and original brief. Patches receive only the issue, target field, and dependencies.
- Compute arithmetic, counts, coverage, and budget checks in code. Return complete requested artifacts plus only downstream metadata; omit repeated inputs and narration.
- Persist exact requests, validated artifacts, versions, usage, cost, failures, and retry lineage. Resume from valid checkpoints. Never present fabricated or substituted assets as successful generation.
- Reserve concurrent paid work against the run budget. Retry only a named recoverable failure within limits; inspect images again after editing.
- Compare paired briefs with provider settings held constant. Blind judges, inspect pixels, report ties and failures, and separate token estimates from measured usage and creative scores from real ad performance.
