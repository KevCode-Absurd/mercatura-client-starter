# Reference and shot templates

Adapt the fields below to the actual attachments, route and approved plan. Brackets are placeholders; never send an unresolved tag or promise references that have not been attached. The two supplied lessons contribute identity-versus-world separation, matching coverage, visible behavior and purposeful timing. Their example story and provider settings are not defaults.

For the supplied Nuova Era video prompter's role/exclusion/scope, timed-event and conditional edit/extension method, use [Video prompt architecture](../../production-principles/references/video-prompt-architecture.md). Keep the current schema and chosen format/audio rules rather than importing the source's fixed delivery conventions.

## Identity reference

```text
Create an identity reference for [adult A and optional adult B], with [the views supported by this workflow]. Keep each face, age, build, hair, skin detail, outfit and accessory consistent across views. Use a plain neutral background and soft even light to inspect identity. This reference supplies appearance only; its background, lighting and panel layout do not become the film scene. [Exact cast descriptions.] No product or caption.
```

## Scene master

```text
[Identity attachment] defines [character] only. Create one full-frame [aspect] photoreal cinematic scene, not a reference grid. [Visible cast and blocking.] [Location and its spatial anchors.] [Product/photo binding and actual prop states.] [Physical light sources, positions, direction and falloff.] [Camera height, distance and angle.] [Focus target and foreground/background softness.] [One visible event already underway.] [Observable performance and gaze.] Preserve natural skin and believable materials. This frame establishes the approved scene world.
```

## Matching coverage

```text
[Identity attachment] defines [A/B]; [scene master attachment] defines room geometry, light sources and grade; [product photo when shown] defines the real product. Create one frame of the next shot: [visible cast], [shot size, camera position and direction], [gaze target], [one event and performance]. Preserve wardrobe, scale and prior object state. Change framing as this shot requires, not the room layout or physical light positions. A reverse angle can change their screen positions. Only the subjects this shot names appear. [Focus planes.] No copied reference-grid layout.
```

## Timed scene plan

```text
Intention: viewer expects [X], discovers [Y], understands [supported product role].
References: [actual tags, named roles, relevant exclusions and shot scope].
Continuity: [fixed cast], [set anchors], [light sources], [prop holders/support, count and starting states].
[start-end] [purpose]: [visible cast], [size/height/angle], [trigger → one ordered event/contact → completion state], [gaze/performance], [dominant move], [focus].
Move: [starting crop → named path and pace → new information visible at arrival; settle or exit moving]. Simpler/shorter when a face fills the frame. Subject time: [real speed, or the deliberately slowed event].
Dialogue: [named speaker and exact approved words]. Delivery: [tone and feasible pause].
Voice identity: [same accent, register, texture and baseline cadence for each named speaker across clips; local tone does not replace it].
Next cut: [what changes / what stays].
Payoff: [the supported use or detail and time for recognition].
Audio: [user's enabled/disabled voice, source sounds and music choices].
```

For app output map these decisions into its existing shot-plan fields. Timestamps should span the accepted segment duration. Treat handoffs as actual cuts or available continuity references rather than claiming unsupported seamless extension.

## One-variable repair

```text
Keep the approved cast, wardrobe, location, shot purpose and dialogue. Correct only [specific defect] in [affected shot]: use [identity / master / product reference] for [its role]. Preserve [unrelated framing, performance and physical state]. Compare this shot at the same scale before changing another variable.
```
