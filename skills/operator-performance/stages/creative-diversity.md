# Fill the actual creative gap

Given allowed formats and tagged existing/planned creatives, vary the argument, buyer stage, buyer, hook, composition, visual treatment and product moment independently. A different font, color or crop alone is a variation, not a new concept. Reuse a supported format ID; visual treatments may cross formats. For static-only work, judge coverage within static formats and permitted archetypes. Never require video, UGC or a collection to pass.

Fill compatible missing combinations first, then excessive repetition. Allocate by the brief's actual goals and available evidence, not universal spend-share quotas. Product-only concepts need no presenter. Demographic changes must alter a relevant situation, objection or use moment rather than merely swapping a face. Do not infer age, gender or buying behavior from unlabelled images.

Use proof-led concepts only with matching approved evidence; use founder stories only with a supplied real story. Where proof is absent, select a demonstration, educational, product, situation or identity argument instead. Preserve offer terms and product-operation facts.

Return only requested brief fields plus existing IDs for format, buyer/stage, argument, gap and evidence. Each opening is actual copy or a specific visible action. Similarity is a creative-review proxy, never a platform Entity ID or a prediction of ad performance.
