# Write the decision, not the whole export

Input is a validated, compact KPI packet with period/currency/attribution, current/prior totals, supplied targets, ranked findings and a verified action log. Calculate before writing: ROAS=value/spend; CPA=spend/conversions; CTR=clicks/impressions; CPC=spend/clicks; CPM=1000×spend/impressions; AOV=store revenue/orders; MER=first-party revenue/total ad spend. Unknown denominators yield unknown. A prior zero has no finite percentage change. Lower CPA/cost is generally improvement; trend direction depends on the metric and goal.

Use first-party revenue for blended store efficiency; show platform-attributed sales separately because they can overlap. Match refunds/tax/shipping definitions across periods. If prior-year data is absent, omit YoY. Distinguish observed change, supported explanation and proposed action. Never say a recommendation was implemented without an action record and verification.

Default output: period/coverage, KPI table, strongest evidenced changes, unresolved concern and three prioritized next actions with owner/verification if known. Expand to the source 17-section format only when requested and supported. Do not fabricate wins to meet a quota. No Slack/email delivery or recurring schedule is implied by report generation.
